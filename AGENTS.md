# AGENTS.md

## Session Rules
- Load and use `caveman` skill for all repo work.
- Use `caveman-compress` when compressing natural-language memory/instruction files.

## Repo Shape
- Rust edition 2024 workspace. Root `Cargo.toml` lists only `vast`, but `lvast` is also a workspace member via `vast` path dependency; `cargo metadata --no-deps` shows both crates.
- `vast/` is binary entrypoint (`vast/src/main.rs`). It currently calls `lvast::bindings::svb::SVBGetSDKVersion()` and prints SDK version.
- `lvast/` is library crate wrapping SVB camera SDK FFI. `lvast/src/bindings/svb.rs` is generated by bindgen; avoid hand edits unless intentionally patching generated output.
- `external/svb/` contains vendored SVB SDK header and per-arch native libs. `lvast/build.rs` maps target arch to `external/svb/lib/{x64,x86,armv8,armv7,armv6}`.

## Native Build Gotchas
- `lvast/build.rs` links static `SVBCameraSDK` plus dynamic `stdc++`, `usb-1.0`, `pthread`, and `m`; host needs C++ toolchain, libclang/bindgen support, and `libusb-1.0` linkable.
- Bindings regenerate during build from `external/svb/include/SVBCameraSDK.h` into `lvast/src/bindings/svb.rs`.
- Unsupported Rust target arch panics in `build.rs`; supported mappings: `x86_64 -> x64`, `x86 -> x86`, `aarch64 -> armv8`, `armv7 -> armv7`, `arm -> armv6`.

## Commands
- Check compile: `cargo check --workspace`.
- Run tests: `cargo test --workspace` (currently zero tests, but builds both crates and doctests `lvast`).
- Compile tests only: `cargo test --workspace --no-run`.
- Strict lint: `cargo clippy --workspace -- -D warnings`.
- Run sample binary: `cargo run -p vast` should print `SVB SDK Version: v1.13.4` with current vendored SDK.
- Format check: `cargo fmt --all -- --check`; currently fails on pre-existing whitespace/newline diffs in `lvast/build.rs`, `lvast/src/lib.rs`, and `vast/src/main.rs`.
- Update vendored SVBONY/SVB SDK files: `scripts/update-svbony-drivers.sh [--no-check] <sdk-dir|sdk-archive|sdk-url>`; it backs up `external/svb` and runs `cargo check --workspace` unless skipped.
